# Happy Birthday Fahmida — GitHub Pages

Open `index.html` to preview. All six pictures are included in this folder.

## Birthday Finale
When the finale section enters view, the large 10-to-0 countdown displays for 10 seconds. Then a gift surprise runs, followed by two pink curtains opening slowly (3.2 seconds) to reveal `birthday-celebration.png`. Use **Celebrate Again!** to replay.

## Publish
Upload all files inside this folder to the root of your GitHub repository (not the ZIP itself). In repository Settings > Pages, select Deploy from a branch, main, /(root).

Internet access is required for Tailwind, fonts, icons and confetti CDN resources. The images are local.

Photo display: All slideshow images retain their complete portrait/landscape framing; the frame adapts to each photo. The finale photo also uses contain mode.
